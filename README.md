# 燃气信息查询 (bj_gas)

[HACS](https://hacs.xyz/) 自定义集成，通过北京燃气手机 App 的接口查询燃气表数据。

## 功能

绑定手机号后，自动发现名下燃气户号，为每个户号创建以下传感器：

| 传感器 | 说明 | 单位 |
| --- | --- | --- |
| 燃气费余额 | 账户余额 | 元 |
| 当前燃气梯 | 当前阶梯级数 | — |
| 当前气价 | 当前阶梯气价 | 元/m³ |
| 当前阶梯剩余额度 | 当前阶梯剩余可用气量 | m³ |
| 本年度用气量 | 年度累计用气量 | m³ |
| 当月用气量 | 当月用气量 | m³ |
| 气表电量 | 燃气表电池电压 | V |
| 阀门状态 | 气表阀门开关状态 | — |
| 燃气月账单 | 月度历史账单（属性中包含各月明细） | m³ |
| 燃气日账单 | 每日历史账单（属性中包含逐日明细） | m³ |

数据每 10 分钟自动更新，支持 Token 过期自动重新认证。

## 安装

1. 在 HACS 中点击「自定义仓库」，添加本仓库 URL，类别选择「集成 (Integration)」。
2. 安装完成后，在「设备与服务」中添加「燃气信息查询」集成。
3. 输入燃气 App 的手机号和密码，选择要绑定的燃气户号即可。

## 配置

- **手机号**：燃气账号绑定的手机号
- **密码**：燃气账号密码

配置完成后会自动发现该手机号下的所有燃气户号，可多选。

## 注意事项

- 本集成通过燃气官方 App 的非公开接口获取数据，仅供个人使用。
- 若接口发生变动可能导致集成失效，请在 [Issues](https://github.com/zhaoyibo/bj_gas/issues) 反馈。
